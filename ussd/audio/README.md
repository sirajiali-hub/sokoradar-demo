# Recorded voice alerts

Real voices sound far better than a computer voice. Put one recording per county and language here, named
`<county>_<language>.mp3`, for example `kitui_en.mp3`, `kitui_sw.mp3`, `kitui_so.mp3` (county in lower case,
spaces as `-`, e.g. `homa-bay_sw.mp3`). Read the exact script the dashboard shows for that county and language.

When a recording exists, the dashboard plays it and phone calls play it; otherwise the computer voice reads the script.
